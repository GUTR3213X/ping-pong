Just a Ping-pong game.

You can probably build it with:

## Linux:
```sh
make
```

## Windows 10 (Windows 11 requires manual installation of `make`):
```cmd
mingw32-make
```

## MacOS:
```zsh
make
```

and run it with:

## Linux
```sh
python main.py
```

## Windows
```cmd
python main.py
```

## MacOS
```zsh
python main.py
```

(you can close it with "x")
